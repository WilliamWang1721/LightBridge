# 0.3.7 版本更新

## 新增功能
1. 控制台界面升级为 shadcn 风格
    - 侧栏、仪表盘、模型分布和 Token 趋势改用 React + shadcn 组件。
    - 侧栏用户菜单、折叠分组与移动端抽屉统一到同一套导航结构。

2. 外观设置支持运行时 shadcn 预设
    - 系统设置可配置显示模式、界面语言和运行时外观预设。
    - 未配置或预设无效时回退到产品默认外观。

## 优化调整
1. 精简 Vue 布局壳
    - Vue 侧栏改为承载 React 导航，移除桌面端折叠状态。
    - 移除分发导航的 DOM 注入与 MutationObserver 同步，避免重复写入。

2. 仪表盘与设置页布局
    - 管理仪表盘卡片与图表改为响应式网格。
    - 深浅色模式和语言切换收口到系统设置的显示偏好。

## 升级说明
1. 本版本无需数据库或配置迁移
    - 升级二进制或容器并重启服务即可生效。
    - 前端为界面重构，请同时升级前后端。
